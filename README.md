# Library Management System

A Library Management System built with Java to simplify library operations, including managing books, tracking availability, and organizing library records.

## Features

- **Book Management** — Add, view, update, and manage book records.
- **Book Search** — Find books by title, author, or other available details.
- **Issue and Return** — Track books issued to users and manage returns.
- **Availability Tracking** — Monitor available and borrowed books.
- **Record Management** — Maintain organized library data.

## Tech Stack

- **Language:** Java
- **Build Tool:** Apache Maven
- **UI:** JavaFX
- **Version Control:** Git

## Prerequisites

Make sure you have the following installed:

- Java JDK
- Apache Maven
- Git

## Future Improvements
